# Moment

온전히 시간에 집중하는 전체화면 시계입니다. 별도 빌드나 외부 서버 의존 없이 동작하며, 필요한 웹폰트 파일을 사이트에 함께 포함합니다.

## 실행

저장소 루트에서 실행합니다.

```sh
python3 -m http.server 8080
```

브라우저에서 <http://localhost:8080/clock/>를 여세요. 기존 정적 호스팅에도 `clock/` 폴더를 그대로 올릴 수 있습니다.

동작 검증: `node --test tests/moment-clock.test.cjs`

## 기능

- 잠금화면 스타일의 부드럽고 두꺼운 숫자를 사용합니다. [Open Runde Semibold](https://github.com/lauridskern/open-runde)의 숫자 윤곽을 SVG 경로로 변환해 기기마다 같은 모양으로 표시하며, 폰트 다운로드나 로딩이 필요하지 않습니다. 라이선스는 `OpenRunde-LICENSE.txt`에 포함했습니다.
- 설정의 **숫자 스타일**에서 라운드 / 모던 / 슬림 / 모노 / 클래식 / 디지털을 미리 보고 고를 수 있습니다. 선택은 브라우저에 저장되며 디지털 숫자, 초 표시와 아날로그 눈금에 적용됩니다.
- 웹폰트는 숫자와 콜론만 포함한 WOFF2로 총 15 KB입니다. 웹폰트도 SVG 텍스트로 그려 확대해도 선명하며, 로딩이 완료된 후 스타일을 바꿉니다. 로딩 실패 시 현재 시계를 유지하고 다시 선택할 수 있습니다. 출처와 라이선스는 `fonts/README.md`에 정리했습니다.
- 아날로그 다이얼, 바늘, 아이콘도 SVG 벡터입니다. 배경은 CSS 그라디언트로 그립니다.
- 시침과 분침은 두께감 있는 둥근 캡슐 모양입니다. 디지털의 시·분이 바뀔 때는 바뀌는 숫자만 0.48초 동안 제자리에서 교차 페이드합니다.
- 기본 스타일과 모든 웹폰트 스타일의 숫자·콜론·초 표시에 고정된 자리를 사용합니다. 숫자 조합이 바뀌어도 전체 폭과 각 자리의 중심이 유지됩니다.
- 숫자 사이와 콜론 주변의 간격은 글꼴별 획의 굵기와 실제 숫자 폭에 맞춰 따로 조정합니다. 스타일마다 전체 폭은 다르지만, 같은 스타일에서는 시각이 바뀌어도 간격이 유지됩니다.
- 시스템의 동작 줄이기 설정에서는 페이드를 생략합니다. 탭으로 돌아올 때도 현재 시각을 즉시 표시합니다.
- 디지털 / 아날로그, 밝게 / 어둡게 / 시스템 테마, 12 / 24시간 형식, 초 / 날짜 표시를 설정할 수 있습니다.
- 조작부는 4.5초 뒤 숨겨지며 포인터, 터치, 키보드 입력으로 다시 나타납니다.
- 설정은 브라우저의 로컬 저장소에 보관합니다. 기기의 현재 시각과 시간대를 사용합니다.
- 초침은 부드럽게 이동합니다. 시스템의 동작 줄이기 설정을 따르며 숨겨진 탭에서는 렌더링을 멈춥니다.

| 단축키 | 동작 |
| --- | --- |
| F | 전체화면 시작 / 종료 |
| T | 밝은 / 어두운 테마 전환 |
| A | 디지털 / 아날로그 전환 |
| S | 초 표시 전환 |
| Esc | 설정 닫기 / 브라우저 전체화면 종료 |

## 화면 꺼짐 방지

[Screen Wake Lock API](https://developer.mozilla.org/en-US/docs/Web/API/Screen_Wake_Lock_API)를 사용하고 기본으로 활성화합니다. HTTPS 또는 `localhost`와 지원 브라우저가 필요합니다. `file://`로 여는 대신 위의 로컬 서버를 권장합니다.

다른 탭으로 이동하거나 앱을 전환하면 브라우저가 잠금을 해제할 수 있습니다. 다시 이 탭이 보이면 잠금을 재요청합니다. 운영체제의 절전 정책, 낮은 배터리 또는 브라우저 제한으로 요청이 거절될 수 있으며 화면 상단과 설정에 실제 상태를 표시합니다. 상단 상태 버튼으로 다시 시도할 수 있습니다.

전체화면은 브라우저가 지원하는 환경에서 버튼 또는 F 키로 진입합니다. 지원하지 않는 모바일 브라우저에서는 안내가 표시됩니다.
